# Financial-Gemi-Analyst 📈

Botun çalışması için gerekli talimatlar aşağıdadır.

## Hızlı Başlangıç (Windows)
En kolay yol: **`run_dashboard.bat`** dosyasına çift tıklayın. 
Bu dosya otomatik olarak kütüphaneleri yükler ve uygulamayı açar.

## Manuel Kurulum

Eğer elle çalıştırmak isterseniz:

1.  **Gerekli Kütüphaneleri Yükleyin:**
    Terminali açın (bu klasörde) ve şu komutu yazın:
    ```bash
    pip install -r requirements.txt
    ```

2.  **Uygulamayı Başlatın:**
    Şu komutu yazarak arayüzü açabilirsiniz:
    ```bash
    streamlit run dashboard.py
    ```

Tarayıcınızda otomatik olarak açılacaktır (Genellikle `http://localhost:8501`).
